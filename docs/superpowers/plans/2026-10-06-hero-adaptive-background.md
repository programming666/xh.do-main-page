# Hero 整页背景与自适应组件配色

用户已选择：整个首页使用 Hero 媒体作为背景，导航、介绍、项目及联系方式叠在背景上。保留编辑式排版，不保留独立的右侧图片面板。

## 方案

- 公共容器承载全视口背景层，覆盖页面滚动期间的背景；移动端使用固定尺寸背景元素而非 background-attachment。
- 复用 TechBackground 的分主题素材、轮播、视频、裁切及首帧优化。全页模式关闭组件原有蓝色网格和光效，遮罩改为取色后的主题底色。
- 对当前图片缩小取样，生成底色、前景色和强调色。根据图片明暗选择深浅组件表面，并校正文字/强调色对比度。轮播切图后同步重新取色，过渡平滑；尊重减少动态效果设置。
- 视频仅从封面取色，不持续读取视频帧。取色遇到缺图、CORS、超时或 canvas 失败时回退后台对应主题的手动颜色。不增加服务端任意 URL 抓取接口。
- 正文、导航与项目卡片使用有足够遮盖度的取色表面，保证复杂图片上可读；页面外层不再覆盖整块不透明底色。
- 后台新增背景来源（Hero 媒体 / 自定义背景）与自动配色开关；关闭自动配色后使用既有深浅主题配色。保留原自定义背景配置。旧图文左右/比例字段保留数据兼容，但移除失去意义的编辑控件。
- appearance JSON 增量新增默认字段，无需数据库迁移。现有媒体及站点文案不改变。
