# 编辑式个人主页与可配置外观

日期：2026-10-05

## 已确认的方向

采用视觉原型 A「编辑式个人主页」：大字排版、非对称图文、充足留白、克制分隔线，默认暖纸色与墨绿，深色模式采用对应的深墨色。移除原型中的 ® 装饰。以有设计约束的配置界面实现自定义，不制作自由页面搭建器。

范围包括公共首页、公共导航、友链页的视觉一致性，以及支持这些外观选项的后台配置。后台业务表单以可用性与一致性为主，不扩展为新的 CMS。不得改变认证、授权、二次验证或审计策略。

## 公共页面

### 导航

显示现有 Logo 或站名、项目和关于锚点、按现有开关控制的友链入口、语言切换、主题切换。不添加注册商标符号。小屏幕采用可操作且不会溢出的紧凑布局。隐藏模块时不显示对应锚点入口。

### 首屏

默认左侧为眉题、主标题、副标题与现有 CTA，右侧为独立媒体展示区域。正文不直接压在图片上。保留现有 Logo 和翻译内容，不硬编码原型示意文案。

支持媒体位于左侧或右侧，媒体宽度使用有限的比例预设，支持隐藏媒体。手机端统一为文字在上、媒体在下；隐藏媒体时文字自然扩展，不保留空栏。

现有媒体类型、通用/浅色/深色素材、轮播、视频封面、裁切、位置、遮罩及滚动效果继续有效。区域尺寸变化后仍应使用既有裁切算法，不能引入首帧裁切跳动。旧的背景设置指向首屏媒体区域，不被自动当作整页背景。

### 内容区

关于、项目、联系方式支持开关和排序，首屏始终位于最上方、页脚始终位于最下方。使用固定模块集合而不是任意区块编辑器。

项目支持编辑式列表和卡片两种展示，均保留标题、简介、封面、技术栈、详情及现有演示/仓库入口。空项目显示已有本地化空状态。空联系方式不留下占位面板。

友链页沿用首页的颜色、宽度、间距及背景体系，保留现有内容和跳转行为。

## 外观配置

通过独立外观配置区域集中管理，用选择器、颜色输入和有边界的数值控件提供配置。不接受任意 CSS 或 HTML。

- 分主题配置：页面背景底色、正文色、强调色。
- 页面宽度：紧凑、标准、宽版预设。
- 间距密度：紧凑、舒展预设。
- 首屏媒体：显示开关、左右位置、窄/均衡/宽比例预设。
- 内容模块：显示开关及顺序调整。
- 项目展示：列表或卡片。

暖纸色与墨绿为新增外观设置的默认值，不作为不可修改的样式常量。现有媒体特效的强调色和渐变设置维持原有含义，新界面明确区分「整页外观」和「首屏媒体效果」，避免同名配置互相覆盖。

## 整页自定义背景

整页背景与首屏媒体是两个独立配置层。首页和友链页共用整页背景；后台不套用用户上传的整页背景，以保持配置界面可读。

浅色和深色各有独立设置，支持三种模式：

1. 纯色：使用当前主题的页面背景底色。
2. 渐变：两种颜色与 0–360 度角度。
3. 图片：上传或填写图片 URL；居中 cover 展示、不平铺；可配置遮罩浓度 0–90%。

整页背景不支持视频，视频仍属于首屏媒体功能。整页图片使用现有 backgrounds 上传分类允许的图片格式，但不接受视频作为该字段的输入。图片 URL 允许安全的站内路径及 HTTP/HTTPS 资源，不接收脚本或任意 CSS 表达式。

图片为空、加载失败或对应模式没有可用资源时，页面底色始终存在。图片遮罩使用当前主题底色，内容区域保留主题底色支持的表面与可读文字。不会承诺任意用户配色都自动满足对比度，默认方案必须满足正文可读性。

移动端采用静态背景层，不依赖 background-attachment: fixed，不加入重型动画。切换主题时不串用另一主题的整页图片。

## 数据与保存

持久化到 SiteSettings 的外观字段，保留既有字段含义及默认行 id="default"。新增字段需要 Prisma migration，并同步默认值、读取映射、Zod 完整/补丁 schema、站点 PATCH 合并与写入逻辑。

可将相关外观字段作为结构化设置组合，但必须经过服务端完整校验，不直接信任数据库中的 JSON 或浏览器输入。模块顺序必须来自允许的固定模块键、无重复、集合完整；颜色、数值范围、枚举和 URL 必须校验。

后台保存走 withAdminApi 保护的写入接口并记录审计；失败显示错误并保留未保存的输入，成功明确提示保存完成。公共内容继续使用既有 ISR 机制，界面不承诺保存后所有 CDN 缓存立即更新。

升级后旧站点内容与媒体配置保持不变；新增外观字段采用默认值。不会清空或重置数据库，不修改管理员凭据和环境变量。

## 组件边界

- 外观解析与默认值：集中定义可用枚举、主题配置及兼容回退，供服务端与配置表单使用。
- 公共视觉容器：仅在公共页面应用主题变量、宽度、密度及背景层，不把整页图片传播到后台。
- 首页呈现：组合首屏及固定内容模块，处理排序和隐藏。
- 项目呈现：复用项目数据与行为，根据样式选项渲染列表或卡片。
- 外观设置表单：编辑并保存配置，复用上传控件；不要把复杂编辑逻辑塞入首页组件。

保留 next-intl 导航、主题 provider、现有媒体组件与性能优化。正式实现之前读取当前安装版本的 Next.js 相关文档。

## 验收

- 桌面呈现 A 的编辑式布局，无 ®；中英文均可用。
- 360px 手机、平板与桌面无横向溢出；长标题与长项目描述可正常换行。
- 深浅主题的背景、文字和按钮同步变化；减少动态效果偏好得到尊重。
- 整页纯色、渐变、上传图片和链接图片均能保存并在刷新后恢复，首屏媒体不受整页背景配置影响。
- 空图片和加载失败时有底色兜底；两主题图片各自独立。
- 首屏左右交换、比例、隐藏，项目列表/卡片，模块排序/开关以及宽度/间距预设均生效。
- 模块隐藏后没有无效导航锚点；项目、友链、联系入口保持原有行为。
- 后台保存拒绝不合法的颜色、URL、越界数字、未知模块及重复顺序。
- 旧内容不丢失，站点 PATCH 仅改某字段时不会重置其他设置。
- 运行针对外观解析与校验的测试、ESLint、生产构建，并在真实浏览器检查关键布局与配置链路。当前没有配置测试框架，实现计划选择最小必要的测试方式，不为此引入重量级端到端基础设施。

## 不在范围内

自由拖拽搭建、自定义 CSS/HTML、任意添加模块、多站点主题市场、全站视频背景、认证系统改造、自动部署。未获明确指令不提交 Git commit 或推送远端。
